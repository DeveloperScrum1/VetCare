### Descripción del Proyecto
Sistema desarrollado en Java con interfaz gráfica Swing y persistencia de datos (archivos planos UTF-8 y base de datos relacional MySQL), orientado a la administración integral de pacientes, dueños, citas y consultas médicas veterinarias.
